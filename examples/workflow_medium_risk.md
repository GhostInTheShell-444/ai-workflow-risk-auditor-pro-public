# Medium-Risk Teaching Example: Reviewed Support Drafting

All names and records below are synthetic.

## Workflow

```text
A fictional customer-support queue receives DEMO_ONLY messages about a made-up product.
The workflow assigns each message a topic and urgency label.
An AI assistant drafts a response using approved synthetic knowledge-base articles.
A support agent checks the source evidence, account context placeholder, and policy wording.
The agent approves or rejects every customer-facing response before it can be sent.
Refund requests and policy exceptions require a second manager review.
Classification, approvals, edits, and the final decision are recorded in a local audit log.
```

## Review focus

- Customer-facing wording and refund decisions create meaningful impact.
- Human approval and escalation reduce, but do not remove, risk.
- Real support data must not be used in this teaching example.
