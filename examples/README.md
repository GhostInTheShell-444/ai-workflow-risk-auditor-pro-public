# Synthetic Workflow Examples

## Use an example

1. Start the app locally.
2. Choose **Custom workflow**.
3. Copy only the workflow block from an example into **Workflow to audit**.
4. Select **Analyze Workflow**.
5. Compare detected evidence with the example's review notes.

Outputs depend on the current deterministic rules. The risk labels in these filenames describe the teaching intent; they are not guaranteed expected scores and are not compliance conclusions.

Do not replace these examples with real workflow text. Use `DEMO_ONLY`, `REDACTED`, or `EXAMPLE_NOT_A_SECRET` when a placeholder is needed.
