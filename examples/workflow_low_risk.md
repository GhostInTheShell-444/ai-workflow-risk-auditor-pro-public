# Low-Risk Teaching Example: Internal Summarization

All content below is synthetic.

## Workflow

```text
A local folder contains fictional public-domain training articles with no personal data.
An AI assistant produces a short draft summary for an internal learning exercise.
A human editor compares the draft with the source article before accepting it.
The draft is not sent externally and cannot trigger any action.
The source, draft, editor decision, and final summary are logged locally.
```

## Review focus

- No credentials, personal data, production records, or external actions are intended.
- Human review occurs before acceptance.
- Logging supports traceability.
