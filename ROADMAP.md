# Roadmap

The roadmap is directional, not a delivery commitment. Local-first deterministic analysis remains the default architecture.

## Near term

- Capture privacy-reviewed synthetic screenshots and complete human visual QA.
- Review Light, Dark, French, and Hebrew RTL presentation at common desktop widths.
- Expand synthetic workflow scenarios and sample reports.
- Perform deeper professional review of French and Hebrew wording.
- Add optional PDF export without making a cloud renderer mandatory.

## Later evaluation

- Improve accessible keyboard and screen-reader testing.
- Add further deterministic rule coverage and documented control profiles.
- Expand CI selectively with static analysis and dependency-policy checks.
- Evaluate optional future automated pull-request review workflows after publication, with no vendor key or automation added to the initial public repository.
- Improve local-only model diagnostics while keeping deterministic fallback authoritative.

## Explicit non-goals

- No SaaS or cloud processing by default.
- No hidden telemetry.
- No automatic production actions or remediation.
- No replacement for legal, compliance, privacy, security, or human governance review.
